# Research v0.9d Strict Candidate-Family Discovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify the Research v0.9d strict candidate-family discovery checkpoint from deterministic QuantumRandy export through RandysLab BTC/ETH strict review, correlation diagnostics, failure memory, and the final v0.9d verification report.

**Architecture:** QuantumRandy owns deterministic research-only candidate export, failure-memory conversion, and final documentation. RandysLab remains the strict judge and consumes the exported JSONL without source changes. The workflow preserves declared BTC scope while using ETH only as diagnostic evidence.

**Tech Stack:** Python 3.11, pytest, pandas, QuantumRandy formula/export utilities, RandysLab strict4h candidate sensitivity/review/correlation scripts.
